# DatePilot.online

DatePilot.online is a focused date, calendar, and time utility platform for calculating, understanding, comparing, and working with dates and time.

## Implementation

The application is a Vite React TypeScript site. It includes the home experience, date and time tool indexes, the initial calculator routes, guide routes, and trust pages.

```text
npm install
npm run dev
npm run build
npm run lint
```
