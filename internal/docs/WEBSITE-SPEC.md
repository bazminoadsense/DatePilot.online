# DatePilot Website Specification

## AdSense-first quality requirement

Every page and feature must provide genuine value to the user independently of advertising. Content must be original, accurate, useful, clearly structured, and relevant to DatePilot's primary purpose. We will not create pages solely to increase page count, target keywords, or display ads.

## Information architecture

Primary navigation: Home, Calculators, Calendar, Time, Guides, About. Main content routes comprise 30 useful pages across calculator, calendar, time, guide, and FAQ sections. Trust and support routes are additional: About, Contact, Privacy Policy, Cookie Policy, Terms, Disclaimer, and Report an Error. Tool pages include a purpose, accessible inputs, results with assumptions, methodology, example, limitations, related tools, and useful FAQs where needed.

## Functional requirements

Forms support keyboard navigation, validation, reset without reload, locale-safe date controls, visible assumptions, mobile layouts, and accessible result updates. Canonical pages need unique metadata, stable URLs, internal links, sitemap, robots directives, and accurate structured data where appropriate.
