# DatePilot Design System

DatePilot should feel precise, calm, useful, and quietly distinctive. Use a light high-contrast foundation, deep ink, warm paper surfaces, and one clear accent. Use expressive readable typography, stable calculator layouts, visible focus states, semantic landmarks, accessible labels, clear errors, reduced-motion support, and comfortable mobile touch targets.

Keep the calculator near the top, explanations constrained for reading, and navigation predictable. Ads must never resemble results, obscure controls, interrupt a calculation, or destabilize layout.
