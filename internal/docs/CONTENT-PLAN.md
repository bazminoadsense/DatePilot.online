# DatePilot Content Plan

Create original explanations that help people use date and time calculations correctly. Initial guides cover counting days, inclusive versus exclusive dates, leap years, ISO weeks, working days, elapsed time, UTC offsets and daylight saving time.

Use [KEYWORD-RESEARCH.md](KEYWORD-RESEARCH.md) as the gate for new content. It records candidate intent, cluster consolidation, evidence requirements, content gaps, publishing phases, and briefs. A keyword candidate is not a publication instruction; validate demand and the live SERP first.

Each page needs a real user purpose, useful context, methodology, an independently checked example, edge cases, related tools, and a review owner. Do not create pages solely for keyword variations or page count.
