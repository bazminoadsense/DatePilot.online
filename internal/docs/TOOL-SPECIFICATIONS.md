# DatePilot Tool Specifications

All tools must state accepted inputs, calendar/timezone assumptions, endpoint inclusion, precision, invalid-input behavior, and a reproducible example. Test normal, boundary, invalid, leap-day, month-end, year-end, reversed-date, DST, and timezone cases where relevant.

Initial tools: Age Calculator; Date Calculator; Days Between Dates; Add Days; Subtract Days; Working Days Calculator; Day of the Week Calculator; Week Number Calculator; Leap Year Calculator; Countdown Calculator; Time Difference Calculator; Time Zone Converter.

Use maintained date/time logic and IANA timezone identifiers where applicable. Keep calculation logic separate from presentation.
